# 熵潮 · ENTROPY TIDE

👉 **[在线试玩](https://nightsky5819.github.io/entropy-tide/)** · 打开即玩，无需下载

![游戏截图](https://nightsky5819.github.io/entropy-tide/docs/screenshots/01-battle.png)

一个**单文件、零依赖**的俯视角射击小游戏。整个游戏——图形、音效、剧情、存档——都在一个 `index.html` 里，不加载任何外部资源，不联网，双击即玩。

> 用 Canvas 2D 手绘画面，用 WebAudio 实时合成音效，没有任何图片、字体或音频文件。

---

## 玩法

俯视角射击 + Roguelite 强化。清空一波又一波熵潮，每波结束从随机模块里挑一个强化自己。

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` / 方向键（**有惯性，需要预判刹车**） |
| 瞄准 | 鼠标 |
| 射击 | 鼠标左键（按住连发） |
| 冲刺闪避 | `空格` / 鼠标右键（带无敌帧） |
| 暂停 | `P` / `Esc` |
| 快速选卡 | `1` `2` `3` `4` |
| 静音 | `M` |

触屏设备会自动切换虚拟摇杆 + 自动瞄准。

## 系统一览

### 两种模式
- **剧情模式**：目前开放「序章」，共 5 小关，以首领收尾。剧情可一键跳过。
- **无尽模式**：波次无限递进，每 5 波出现首领。也是积累**局外天赋点数**的唯一途径（每清空 3 波 +1 点）。

### 五个载体（职业）
先锋 / 幻影 / 枪炮师 / 噬能者 / 守望者 —— 血量、射速、弹数、移动手感差别很大。

<a id="elite"></a>
### 精英怪「熵潮聚合体」
第 3 波起按波次概率出现（第 3-5 波 20%、第 6-10 波 35%、第 11 波起 50%），每波最多 2 只，首领波不出现。体型 ×1.5、血量 ×3、伤害 ×1.5、分数 ×5。

每只携带 **1 个精英词缀**（共 8 种，同波两只不重复也不冲突）：

| 类型 | 词缀 | 效果 |
|---|---|---|
| 行为 | 迅捷 | 移速 +60%，突进频率翻倍，攻击间隔 -25% |
| 行为 | 分裂 | 死亡时分裂为 4 只小怪 |
| 行为 | 吸血 | 每 2 秒回复 1.5% 最大生命 |
| 行为 | 荆棘 | 被接触时反弹 60% 接触伤害并击退玩家 |
| 防御 | 护盾 | 护盾 = 最大生命 50%，脱战 4 秒回满（先破盾才能伤到本体） |
| 防御 | 相位 | 每 3 秒进入 1 秒相位态：免疫伤害但缓慢漂移 |
| 防御 | 硬化 | 最大生命 +80%，移速 -30%，接触伤害 +30% |
| 防御 | 再生 | 每秒回复 2.5% 最大生命，受伤后 1.5 秒内暂停 |

击杀精英必定掉落生命补给，另有 30% 概率奖励额外强化机会（一局上限 3 次）。

### 波次词缀「熵潮变异」
第 4 波起，每波附带 1 个随机词缀（第 8 波起 40% 概率 2 个），首领波除外。共 12 种，分「熵潮自身变化 / 敌人行为变化 / 战场环境变化」三类，冲突词缀不会同时出现。屏幕右上角常驻显示本波变异。

### 局内事件房「数据裂隙」
每 5 波出现一次（首领波顺延到下一波），出现在升级选择**之前**，不替代升级。每次从 9 个事件里抽 1 个，给 3 个选项，选择不可撤销。

共 9 个事件：数据残骸、故障终端、熵潮裂隙、废弃缓存、静默协议、熵蚀试验、极限压缩、算力共鸣、协议重写。

其中「覆写 / 重写 / 微调」会**真正回退**卡牌效果 —— 不是只删记录，而是按每张卡自己的增量做逆运算撤销数值。详见 [设计说明](docs/DESIGN.md#可回退的卡牌系统)。

### 局外天赋树「底层算力模块」
26 个节点、四层结构（基础 4 / 路径 9 / 交叉 9 / 终局 4），三条路线：红线·算力 / 蓝线·防护 / 绿线·发育，交叉层需要两条线各点出前置。加成对两种模式全部生效，进度存在 `localStorage`，支持消耗 3 点洗点。

### 首领三型
- **熵核**：标准型，血量降到 20% 以下狂暴
- **熵壁**：血牛型，带护盾、移速慢、弹幕最密
- **熵刃**：刺客型，血量最低、移速最快、弹速极高

## 开发与验证

`dev/` 下的脚本**不需要任何第三方依赖**，只用 Node 标准库。绝大多数是「无头 + 真实浏览器」双重验证：

```bash
cd dev

# 无头回归测试：桩化 DOM 与 Canvas，推进 42000+ 帧，覆盖 60+ 项断言
node smoke-test.js

# 真实浏览器验证（Chrome DevTools Protocol，需要本机装了 Chrome）
node r9-check.js      # 卡牌回退 / 事件房
node r8-check.js      # 精英怪出现率 / 事件房 UI

# 数值平衡探针
node balance-probe.js
```

测试脚本会自动定位游戏文件（优先仓库根目录的 `index.html`），所以在 `dev/` 或仓库根目录下运行都可以。

### 验证覆盖的内容
回归测试覆盖：UI 流程闭环、暂停/结算状态机、玩家位移与冲刺积分、相机跟随精度、卡池品质门槛、三型首领的护盾/狂暴/相位、局外天赋树的解锁链与点数规则、词缀抽取与冲突规则、精英怪 8 个词缀的运行时行为与出现率分布、事件房触发与 27 个选项、**23 张卡逐张的应用→回退精确性**。

## 技术要点

- **固定逻辑分辨率** 1600×1000（16:10），渲染到离屏 canvas，再由 `present()` 一次性缩放贴到设备像素 canvas —— 避免缩放导致的模糊与输入错位。
- 战场 2240×1560，**相机跟随**用指数平滑（`k = 1 - exp(-45·dt)`），居中跟随、不做速度预判（早期版本的速度预判 + 低平滑率会造成 200px 级滞后与晕动感）。
- 固定步长 1/60 + 累加器；空间哈希做碰撞；`hitstop` / 屏幕震动 / 闪白做打击感。
- Bloom：提取高亮区域 → 模糊 → `lighter` 合成，全部在视口分辨率下做。
- 主循环包在 try/catch 里，任何一帧异常都不会打断 rAF 链。
- 卡牌回退用**增量记录**而非快照（乘法记比例、加法记差值、开关记原值），因此叠加多张后撤销其中一张仍精确。

更多细节见 [docs/DESIGN.md](docs/DESIGN.md)。
