# 熵潮 · ENTROPY TIDE

👉 **[在线试玩](https://nightsky5819.github.io/entropy-tide/)** · 打开即玩，无需下载

![游戏截图](https://nightsky5819.github.io/entropy-tide/docs/screenshots/01-battle.png)

一个**单文件、零依赖**的俯视角射击小游戏。整个游戏——图形、音效、剧情、存档——都在一个 `index.html` 里，不加载任何外部资源，不联网，双击即玩。

> 用 Canvas 2D 手绘画面，用 WebAudio 实时合成音效，没有任何图片、字体或音频文件。

---

## 玩法

俯视角射击 + Roguelite 强化。清空一波又一波熵潮，每波结束从随机模块里挑一个强化自己。

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` / 方向键（**有惯性，需要预判刹车**） |
| 瞄准 | 鼠标 |
| 射击 | 鼠标左键（按住连发） |
| 冲刺闪避 | `空格` / 鼠标右键（带无敌帧） |
| 暂停 | `P` / `Esc` |
| 快速选卡 | `1` `2` `3` `4` |
| 静音 | `M` |

触屏设备会自动切换虚拟摇杆 + 自动瞄准。

## 系统一览

### 两种模式
- **剧情模式**：目前开放「序章」，共 5 小关，以首领收尾。剧情可一键跳过。
- **无尽模式**：波次无限递进，每 5 波出现首领。也是积累**局外天赋点数**的唯一途径（每清空 3 波 +1 点）。

### 五个载体（职业）
先锋 / 幻影 / 枪炮师 / 噬能者 / 守望者 —— 血量、射速、弹数、移动手感差别很大。

<a id="elite"></a>
### 精英怪「熵潮聚合体」
第 3 波起按波次概率出现（第 3-5 波 20%、第 6-10 波 35%、第 11 波起 50%），每波最多 2 只，首领波不出现。体型 ×1.5、血量 ×3、伤害 ×1.5、分数 ×5。

每只携带 **1 个精英词缀**（共 8 种，同波两只不重复也不冲突）：

| 类型 | 词缀 | 效果 |
|---|---|---|
| 行为 | 迅捷 | 移速 +60%，突进频率翻倍，攻击间隔 -25% |
| 行为 | 分裂 | 死亡时分裂为 4 只小怪 |
| 行为 | 吸血 | 每 2 秒回复 1.5% 最大生命 |
| 行为 | 荆棘 | 被接触时反弹 60% 接触伤害并击退玩家 |
| 防御 | 护盾 | 护盾 = 最大生命 50%，脱战 4 秒回满（先破盾才能伤到本体） |
| 防御 | 相位 | 每 3 秒进入 1 秒相位态：免疫伤害但缓慢漂移 |
| 防御 | 硬化 | 最大生命 +80%，移速 -30%，接触伤害 +30% |
| 防御 | 再生 | 每秒回复 2.5% 最大生命，受伤后 1.5 秒内暂停 |

击杀精英必定掉落生命补给，另有 30% 概率奖励额外强化机会（一局上限 3 次）。

### 波次词缀「熵潮变异」
第 4 波起，每波附带 1 个随机词缀（第 8 波起 40% 概率 2 个），首领波除外。共 12 种，分「熵潮自身变化 / 敌人行为变化 / 战场环境变化」三类，冲突词缀不会同时出现。屏幕右上角常驻显示本波变异。

### 局内事件房「数据裂隙」
每 5 波出现一次（首领波顺延到下一波），出现在升级选择**之前**，不替代升级。每次从 9 个事件里抽 1 个，给 3 个选项，选择不可撤销。

共 9 个事件：数据残骸、故障终端、熵潮裂隙、废弃缓存、静默协议、熵蚀试验、极限压缩、算力共鸣、协议重写。

其中「覆写 / 重写 / 微调」会**真正回退**卡牌效果 —— 不是只删记录，而是按每张卡自己的增量做逆运算撤销数值。详见 [设计说明](docs/DESIGN.md#可回退的卡牌系统)。

### 武器变异「攻击方式重构」（v1.8）
升级池新增 **14 张「变异」卡**（紫色标签），直接改变子弹的飞行与命中方式；全部为稀有 / 史诗品质，与普通强化卡同池三选一。

| 分类 | 卡 | 效果 |
|---|---|---|
| 弹道 | **回旋弹** | 飞到最大距离折返，返程造成 70% 伤害（可再次命中） |
| 弹道 | **分裂弹** | 命中后分裂 3 颗小弹（伤害 40%、射程 60%，小弹不再分裂） |
| 弹道 | **弹射** | 撞墙反弹 2 次，每次伤害 −15% |
| 弹道 | **滞留** | 到达最大距离后停留 1 秒，每秒 30% 范围伤害 |
| 弹道 | **链式** | 命中后向最近敌人跳跃闪电链（50% 伤害，跳跃距离 220） |
| 弹道 | **穿透+** | 穿透不衰减，每穿透 1 个敌人 +5% 伤害（上限 +25%，可叠 3 层） |
| 反馈 | **爆裂弹** | 命中时小型爆炸（半径 70 + 10/层，伤害 60%，可叠 3 层） |
| 反馈 | **索敌弹** | 飞行中向最近敌人偏转（30 度/秒 × 层数，可叠 2 层） |
| 反馈 | **冲击弹** | 命中击退并减速 0.5 秒（首领免疫，可叠 2 层） |
| 反馈 | **腐蚀弹** | 施加腐蚀：每秒 20% 伤害 × 层数，持续 3 秒（可叠 3 层） |
| 反馈 | **吸血弹** | 命中回复 1 点生命（同一子弹对同一敌人只触发一次，可叠 2 层） |
| 机制 | **双管齐发** | 每次射击多发射 1 发，每发伤害 ×0.65（净伤害约 1.3 倍，可叠 2 层） |
| 机制 | **弹幕环绕** | 玩家周围环绕 4 颗高穿透子弹，每 2 秒重生一批（可叠 2 层） |
| 机制 | **延迟引爆** | 命中不造成伤害，标记 1 秒后引爆 120%（高风险高回报） |

**冲突与上限**：5 组成对冲突（回旋↔弹射、滞留↔链式、延迟↔腐蚀、索敌弹↔制导芯片、双管↔多重射击，**双向**生效）；弹道类（回旋/弹射/滞留）最多选 2 张，机制重构类（双管/环绕/延迟）最多选 1 张。变异卡同样支持事件房的「覆写 / 重写」回退，且属于每局内状态、不进存档。

### 无尽模式「层」系统（v1.9）
无尽模式共 **100 波 = 2 个循环 × 5 个层**，每层 10 波。进入新层时有一次 1.5 秒的过渡（层名 + 世界观），背景、网格与场地边框会整体换成该层的主题。

| 层 | 波次 | 主题 | 敌人构成 | 专属词缀 |
|---|---|---|---|---|
| **缓存区** | 1-10 | 蓝 · 干净网格 + 缓慢数据流 | chaser / darter / shooter | 无（保持基础池） |
| **情绪池** | 11-20 | 紫 · 扩散波纹 + 情绪涡流 | + tank / splitter | 焦虑 / 愤怒 / 麻木 / 共鸣 |
| **记忆库** | 21-30 | 金 · 飘落的数据碎片 | + orb | 碎片化 / 回溯 / 残留 / 档案 |
| **核心协议** | 31-40 | 红 · 心跳脉冲 + 边缘告警 | 全部类型 | 干扰 / 限流 / 回响 |
| **自毁倒计时** | 41-50 | 白 · 间歇白闪 + 扫描线 | 全部类型，精英概率极高 | 崩解 / 倒计时 / 崩溃 / 终末 |

- **第二循环（第 51-100 波）**：复用同样 5 个层，敌人血量 ×1.8、伤害 ×1.4、移速 ×1.15、精英率 +20%、分数 ×1.5；开场回满血并给 2 秒无敌。第 100 波（自毁终点）清空即**通关**。
- **层专属词缀与波次词缀共存**：每波 60% 概率抽 1 个层专属词缀，再抽 1 个全局波次词缀（第 8 波起 40% 概率第二个），冲突规则照旧。首领波与第 3 波之前不抽。
- **首领节奏**：其余层每 5 波一只首领，**核心协议层改为每 4 波**（第 32/36/40 波）。
- **层 4 剧情碎片**：每 5 波（第 35、40 波）索菲亚会通过提示说一句话。
- **崩溃 vs 收缩**：两者都缩小场地，取**较大值**而非叠加；崩溃在进入自毁层时即为 20%，之后每波 +5%，上限 30%。

### 局外天赋树「底层算力模块」
26 个节点、四层结构（基础 4 / 路径 9 / 交叉 9 / 终局 4），三条路线：红线·算力 / 蓝线·防护 / 绿线·发育，交叉层需要两条线各点出前置。加成对两种模式全部生效，进度存在 `localStorage`，支持消耗 3 点洗点。

### 存档系统（v1.7）
局外进度（最高分 / 天赋树 / 历史统计）统一保存在**一个** localStorage 对象 `entropyTideSave` 里，自带 `version` 字段与迁移链：游戏更新时旧存档自动升级，导入老存档也一样。标题页与暂停页都有「存档管理」，可**导出 / 导入**存档字符串（Base64，可复制或下载 `.txt`），也可二次确认后重置。v1.6 及以前的两个旧存档 key 会在首次启动时自动合并，玩家无感。

> **存档说明**
> - 进度自动保存在浏览器本地（localStorage），**清除浏览器数据会丢失存档**
> - 无痕模式下关闭标签页后存档消失
> - 更换设备或浏览器时，请用「导出存档」备份，再在新设备上「导入存档」
> - 存档包含版本号，游戏更新时会自动迁移；若存档版本高于当前游戏版本会被拒绝导入（避免数据错乱）

### 首领三型
- **熵核**：标准型，血量降到 20% 以下狂暴
- **熵壁**：血牛型，带护盾、移速慢、弹幕最密
- **熵刃**：刺客型，血量最低、移速最快、弹速极高

## 开发与验证

`dev/` 下的脚本**不需要任何第三方依赖**，只用 Node 标准库。绝大多数是「无头 + 真实浏览器」双重验证：

```bash
cd dev

# 无头回归测试：桩化 DOM 与 Canvas，推进 42000+ 帧，覆盖 80+ 项断言
node smoke-test.js

# 真实浏览器验证（Chrome DevTools Protocol，需要本机装了 Chrome）
node r12-check.js     # 层系统：层判定 / 背景像素级切换 / 过渡冻结 / 层词缀 / 100 波通关
node r11-check.js     # 武器变异：14 张卡表 / 冲突过滤 / 卡面标签 / 逐张实战
node r10-check.js     # 存档系统：导出 / 导入 / 迁移 / 重置 / 刷新持久化
node r9-check.js      # 卡牌回退 / 事件房
node r8-check.js      # 精英怪出现率 / 事件房 UI

# 层背景出图（5 张，供人工审查）
node layer-shots.js

# 数值平衡探针
node balance-probe.js
```

测试脚本会自动定位游戏文件（优先仓库根目录的 `index.html`），所以在 `dev/` 或仓库根目录下运行都可以。

## 技术要点

- **固定逻辑分辨率** 1600×1000（16:10），渲染到离屏 canvas，再由 `present()` 一次性缩放贴到设备像素 canvas —— 避免缩放导致的模糊与输入错位。
- 战场 2240×1560，**相机跟随**用指数平滑（`k = 1 - exp(-45·dt)`），居中跟随、不做速度预判（早期版本的速度预判 + 低平滑率会造成 200px 级滞后与晕动感）。
- 固定步长 1/60 + 累加器；空间哈希做碰撞；`hitstop` / 屏幕震动 / 闪白做打击感。
- Bloom：提取高亮区域 → 模糊 → `lighter` 合成，全部在视口分辨率下做。
- 主循环包在 try/catch 里，任何一帧异常都不会打断 rAF 链。
- 卡牌回退用**增量记录**而非快照（乘法记比例、加法记差值、开关记原值），因此叠加多张后撤销其中一张仍精确。

更多细节见 [docs/DESIGN.md](docs/DESIGN.md)。
